# Simultaneous Localization and Mapping (SLAM) Implementation

This repository contains my personal implementations of various **SLAM algorithms** developed as part of the "Robot Mapping" course (University of Freiburg). The projects cover probabilistic robotics concepts, ranging from EKF-based filters to advanced Graph-SLAM approaches.

##  Overview
The implementations are primarily developed using **MATLAB/Octave**, focusing on the mathematical foundations and algorithmic logic of robot perception and localization.

## 📂 Project Structure
Each folder represents a specific milestone in the course, including the framework, my custom code, and descriptive PDF sheets:

| Milestone | Algorithm / Topic | Key Concepts |
| :--- | :--- | :--- |
|**EKF-SLAM** | Extended Kalman Filter, Prediction & Correction steps. |
|**UKF-SLAM** | Unscented Kalman Filter, Sigma points for non-linearity. |
|**EIF-SLAM** | Extended Information Filter, Information matrix representation. |
|**Grid Maps** | Occupancy Grid Mapping and Log-odds representation. |
|**FastSLAM** | Particle Filters and Rao-Blackwellized mapping. |
|**Least-Squares** | Non-Linear Least Squares and Odometry Calibration. |
|**Graph-Based SLAM** | Pose-Graphs, Landmarks, and Manifold Optimization. |

## Technologies Used
* **Language:** MATLAB / Octave
* **Core Concepts:** Probabilistic Robotics, Multivariate Gaussian Density, Gauss-Newton Optimization, Homogeneous Coordinates.
